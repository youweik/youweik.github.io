🤔 Pencil 是什么？

想象一下：你正在写代码，突然需要画一个界面设计图。传统做法是打开 Figma，画完再截图发给开发。但现在有了 Pencil，你可以在你熟悉的代码编辑器（VS Code / Cursor）里直接画设计图，而且 AI 会帮你画！

简单来说：Pencil = 代码编辑器里的 AI 设计工具。它能让你「边写代码边做设计」，再也不用来回切换工具了。

一句话理解

😰 以前的工作流

  1. 打开 Figma 画设计稿
  2. 截图发给开发
  3. 开发对着截图写代码
  4. 设计改了又要重新来

🤩 用 Pencil 的工作流

  1. 在编辑器里打开 .pen 文件
  2. 用自然语言告诉 AI 你要什么
  3. AI 直接帮你画好设计
  4. 还能自动生成对应代码！

📦 安装方式

Pencil 提供了好几种安装方式，选最适合你的：

方式一：VS Code 扩展（推荐）

1

打开 VS Code

按 Cmd+Shift+X（Mac）或 Ctrl+Shift+X（Windows）打开扩展商店

2

搜索安装

搜索 "Pencil"，认准开发者 High Agency，点击 Install

3

验证安装

创建一个 test.pen 文件并打开，右上角出现铅笔图标就说明安装成功

方式二：Cursor 扩展

和 VS Code 一样，在 Cursor 的扩展商店搜索 "Pencil" 安装即可。

方式三：桌面应用

去 pencil.dev/downloads 下载桌面版：

  • macOS：下载 .dmg 文件，拖到 Applications 文件夹
  • Linux：下载 .deb 或 .AppImage
  • Windows：推荐使用 VS Code 扩展方式

方式四：命令行工具（CLI）

适合喜欢在终端操作的同学，或者需要在 CI/CD 中自动生成设计的场景：

# 安装 CLI（需要 Node.js 18+）
npm install -g @pencil.dev/cli

# 登录
pencil login

# 验证安装
pencil version
安装好 Pencil 后，还需要安装并登录 Claude Code CLI 才能使用 AI 功能： 
# 安装 Claude Code
npm install -g @anthropic-ai/claude-code-cli

# 登录
claude

🔗 理解 MCP（关键概念）

MCP = Model Context Protocol（模型上下文协议）
你可以把它理解为 AI 和设计工具之间的「翻译官」。它让 AI 能读懂你的设计文件，也能帮你修改设计。

通俗理解

想象你去餐厅吃饭：

  • 你 = 用户，说出你想要什么菜（设计需求）
  • 服务员 = MCP，把你的需求传达给厨房
  • 厨师 = AI（Claude），根据需求做菜（生成设计）
  • 厨房 = Pencil，提供做菜的工具和空间

你不需要知道厨房怎么运作，只需要告诉服务员你要什么，厨师就会帮你做好！

工作原理

👤 你输入需求
→
🤖 AI 理解需求
→
📡 MCP 调用工具
→
✏️ Pencil 修改设计
→
👀 你看到结果

安全须知

MCP 服务器完全在你的电脑上本地运行，不会把你的设计文件传到网上。你的设计数据是安全的！
  • ✅ 本地运行，不依赖云服务
  • ✅ 设计文件不会离开你的电脑
  • ✅ AI 的操作需要你确认才生效

🛠️ 核心工具一览

AI 通过 MCP 可以使用以下工具来操作你的设计文件。了解这些工具，你就能更好地指导 AI 做事。

设计操作类

工具名作用通俗理解
batch_design创建、修改、删除设计元素AI 的「画笔」——用来画东西
batch_get读取和搜索设计元素AI 的「眼睛」——用来看设计里有什么
get_editor_state获取当前编辑器状态AI 了解「当前工作环境」
get_variables读取设计变量（颜色、字体等）查看「设计系统配置」
set_variables修改设计变量修改「设计系统配置」

分析检查类

工具名作用通俗理解
get_screenshot给设计截图给设计「拍照」看看效果
snapshot_layout分析布局结构检查元素有没有「排好队」
find_empty_space_on_canvas找到画布上的空位找到画布上的「空地」放新元素

样式指南类

工具名作用
get_guidelines加载设计指南和风格模板，帮助 AI 按照特定风格生成设计

✏️ batch_design 操作详解

batch_design 是最核心的工具，它支持以下操作：

操作语法作用通俗理解
InsertI(parent, {属性})创建新元素「画」一个新东西
CopyC(node, parent, {属性})复制元素「复印」一个已有的东西
UpdateU(node, {属性})修改元素「改」一个东西的属性
ReplaceR(node, {属性})替换元素「换掉」一个东西
DeleteD(node)删除元素「删掉」一个东西
MoveM(node, parent, index)移动元素「搬」一个东西到别处
Image(AI)G(node, "ai", prompt)AI 生成图片让 AI「画」一张图
Image(素材)G(node, "stock", 关键词)搜索素材图片从图库「找」一张图

支持的节点类型

操作示例

以下是 AI 在后台实际执行的操作代码，了解一下就好，正常使用时你只需要用自然语言描述需求：

// 创建一个 1440×900 的深色 Hero 框架
hero = I("document", {
  type: "frame",
  name: "Hero",
  x: 0, y: 0,
  width: 1440, height: 900,
  fill: "#0A0A0A"
})

// 在 Hero 里加一个大标题
title = I(hero, {
  type: "text",
  content: "欢迎来到我的网站",
  fontSize: 48,
  textColor: "#FFFFFF"
})

// 修改标题的颜色
U(title, { textColor: "#6C5CE7" })

// 删除标题
D(title)

💻 命令行工具（CLI）

如果你是终端爱好者，Pencil 还提供了命令行工具，可以不用打开编辑器就能生成设计！

基础命令

# 登录账号
pencil login

# 查看登录状态
pencil status

# 查看版本
pencil version

用 AI 创建设计

# 从零创建一个设计
pencil --out login.pen --prompt "创建一个现代风格的登录页面"

# 修改已有的设计
pencil --in dashboard.pen --out dashboard-v2.pen --prompt "在左侧加一个导航栏"

# 导出为图片
pencil --in design.pen --export hero.png --export-scale 2

可用的 AI 模型

模型特点适用场景
claude-opus-4-6最强大，默认选项复杂设计、完整页面
claude-sonnet-4-6快速且均衡日常设计任务
claude-haiku-4-5最快最便宜简单组件、小修改

交互模式

可以进入一个交互式 shell，逐个调用 MCP 工具：

# 启动交互模式
pencil interactive -o design.pen

# 在交互模式下操作
pencil > get_editor_state({ include_schema: true })
pencil > batch_design({ operations: 'hero=I(document,{type:"frame",name:"Hero",width:1440,height:900,fill:"#0A0A0A"})' })
pencil > get_screenshot({ nodeId: "hero" })
pencil > save()
pencil > exit()

批量处理

创建一个 batch.json 文件，一次生成多个设计：

{
  "tasks": [
    {
      "out": "landing-page.pen",
      "prompt": "创建一个 SaaS 着陆页"
    },
    {
      "out": "mobile-menu.pen",
      "model": "claude-haiku-4-5",
      "prompt": "创建一个移动端菜单组件"
    }
  ]
}

# 运行批量任务
pencil --tasks batch.json

输入以下提示词：

📝 你的提示词：

创建一个现代风格的登录页面，要求：
- 深色背景，居中布局
- 包含邮箱输入框和密码输入框
- 一个醒目的「登录」按钮，使用紫色渐变
- 底部有「忘记密码？」和「注册新账号」链接

- 整体风格简洁现代
4

AI 会在后台做什么

AI 会自动调用以下 MCP 工具来生成你的设计：

// AI 自动执行的步骤（你不需要手动操作）：

// 1. 获取编辑器状态
get_editor_state({ include_schema: true })

// 2. 获取设计指南
get_guidelines()

// 3. 创建页面框架
page = I("document", { type:"frame", width:1440, height:900, fill:"#0a0a0f" })

// 4. 添加 Logo 区域
logo = I(page, { type:"text", content:"MyApp", fontSize:32, fontWeight:"bold" })

// 5. 添加登录卡片
card = I(page, { type:"frame", width:400, fill:"#1a1a2e", cornerRadius:[16] })

// 6. 添加输入框和按钮...

// 7. 截图验证
get_screenshot({ nodeId: page })
整个过程中你只需要说一句话，AI 会自动完成所有操作。你可以在画布上实时看到设计的变化！

❓ 常见问题

Q1：Pencil 免费吗？

Pencil 有免费版本可以使用。AI 功能需要 Claude Code 登录，Claude Code 本身有免费额度。具体的定价政策请参考官方网站。

Q2：MCP 连不上怎么办？

  1. 确保 Pencil 正在运行
  2. 确保 Claude Code 已登录（运行 claude 检查）
  3. 尝试重启 Pencil 和 Claude Code
  4. 在 Cursor 中检查 Settings → Tools & MCP

Q3：.pen 文件可以用 Git 管理吗？

可以！这是 Pencil 的一个核心优势。.pen 文件是开放格式的，可以直接提交到 Git 仓库，追踪设计变更。

Q4：可以导入 Figma 文件吗？

可以。Pencil 支持导入 Figma 文件，方便你从现有设计迁移。

Q5：支持哪些 AI 助手？

AI 助手类型支持状态
Claude CodeCLI + IDE✅ 完全支持
Claude Desktop桌面应用✅ 完全支持
CursorAI IDE✅ 完全支持
WindsurfAI IDE✅ 完全支持
Codex CLICLI（OpenAI）✅ 完全支持

Q6：AI 做出来的设计不满意怎么办？

继续和 AI 对话，具体告诉它哪里不满意，需要怎么改。比如："按钮太大了，改小一点"、"颜色太亮了，用暗一点的蓝"。AI 会根据你的反馈不断调整。
