🧱基础概念层

这些是 AI 领域最基础的概念，理解了它们才能看懂后面的内容。

基础 LLM（大语言模型）Large Language Model

一句话理解：LLM 就是一个「读完了整个互联网的超级学霸」，你问它问题，它能根据学过的知识给出回答。

通俗解释：想象有一个人，他把世界上所有的书、文章、网页都读了一遍。你问他任何问题，他都能基于读过的内容给你一个回答。这就是大语言模型（LLM）做的事情。

它本质上是一个文字接龙游戏——给它一段文字，它预测下一个最可能出现的字。但因为读了太多东西，所以接龙的结果看起来就像是在「思考」。

代表产品：GPT-4o（OpenAI）、Claude（Anthropic）、Gemini（Google）、DeepSeek、Llama（Meta）、Qwen（阿里）
基础 Token（令牌）与 Context Window（上下文窗口）

一句话理解：Token 是 AI 阅读文字的「最小单位」，上下文窗口是 AI 一次能「记住」多少内容。

通俗解释：

  • Token ≈ AI 眼里的「一个字」（但不完全等于）。英文中一个单词大约是 1-2 个 Token，中文一个字大约是 1-3 个 Token。
  • 上下文窗口 ≈ AI 的「短期记忆容量」。如果上下文窗口是 128K Token，那 AI 一次能处理的文字量大概相当于一本 300 页的书。
为什么重要：Token 决定了你用 AI 的费用（按 Token 计费），上下文窗口决定了 AI 能一次处理多少信息。窗口越大，AI 能「记住」的对话越长。
基础 Embedding（向量嵌入）与 Vector DB（向量数据库）

一句话理解：Embedding 就是把文字变成一串数字，让 AI 能理解「意思相近的文字应该靠得近」。

通俗解释：AI 不认识汉字和英文，它只懂数字。Embedding 就是把「苹果」变成类似 [0.23, -0.87, 0.45, ...] 这样的一串数字（向量）。意思相近的词，数字也相近。比如「苹果」和「水果」的数字比「苹果」和「汽车」的数字要接近得多。

向量数据库（如 Pinecone、Milvus、Chroma）就是专门存储这些数字的仓库。当你在 AI 里搜索「水果」时，它能快速找到所有数字相近的内容。

应用场景：RAG（检索增强生成）的核心基础，让 AI 能搜索和理解你提供的私有文档。

📡协议与标准层

这些是 2025-2026 年 AI 领域最重要的「通信协议」，决定了 AI 如何与外部世界交互。

🔥 核心 MCP（模型上下文协议）Model Context Protocol

一句话理解：MCP 是 AI 连接外部工具的「USB 接口」。有了它，AI 就能读取你的文件、调用 API、操作数据库。

通俗解释：

以前的 AI 就像一个被关在房间里的人，只能靠你给他传纸条（输入文字）来工作。MCP 就是给这个房间装上了窗户、电话、互联网，让他可以直接：

  • 📖 读取你电脑上的文件、数据库里的数据
  • ✏️ 操作你的设计工具（如 Figma、MasterGo）
  • 🔧 调用各种外部 API 和服务

由谁制定：Anthropic（Claude 的公司）在 2024 年底发布，2025-2026 年成为行业标准。已得到 OpenAI、Google、Microsoft 等主要厂商支持。

MCP 的意义：它解决了 AI 的「信息孤岛」问题。没有 MCP，每个 AI 工具都要自己开发一套接口；有了 MCP，所有 AI 工具都可以用同一套标准连接外部世界。
🔥 核心 A2A（Agent-to-Agent 协议）Agent to Agent Protocol

一句话理解：如果 MCP 是让 AI 连接工具的「USB」，那 A2A 就是让 AI 和 AI 之间对话的「微信」。

通俗解释：想象你有一个翻译 AI、一个写作 AI、一个设计 AI。A2A 协议让它们可以互相聊天协作：翻译 AI 翻译完后，自动把结果发给写作 AI 润色，再发给设计 AI 排版。

🔌 MCP

AI ↔ 工具

  • 一个 AI 连接多个工具
  • Anthropic 制定
  • 让 AI 能读写外部数据

🤝 A2A

AI ↔ AI

  • 多个 AI 之间互相协作
  • Google 制定
  • 让 AI 团队分工合作
互补关系：MCP 和 A2A 不冲突。MCP 解决「AI 怎么用工具」，A2A 解决「AI 之间怎么配合」。就像一个人既需要工具（MCP），也需要同事协作（A2A）。
🔥 核心 Skill（技能系统）Skills / Skill System

一句话理解：Skill 就是给 AI 写的「SOP 操作手册」，让 AI 在特定场景下按固定流程做事。

通俗解释：AI 很聪明但没有经验。Skill 就是给它装上各种「职业技能」。比如：

  • brainstorming 技能：在写代码前先问你需求（而不是直接动手）
  • TDD 技能：先写测试再写代码（而不是反过来）
  • debugging 技能：按步骤排查 Bug（而不是瞎猜乱改）

代表项目：Superpowers（obra/superpowers）就是一个完整的 AI 编程技能包，包含 12 个技能。

Skills 的本质：就是精心编写的提示词文档（Prompt），通过 Hook 机制在合适的时机自动加载。不是代码，而是「行为规范」。

🤖Agent 智能体层

这是 2025-2026 年最火的方向——让 AI 从「只会聊天」变成「会干活」。

🔥 核心 AI Agent（AI 智能体）

一句话理解：Agent = AI + 行动力。不再只是回答问题，而是能自己规划、使用工具、执行任务的「AI 员工」。

通俗解释：

💬 普通 AI 对话

你问一句，它答一句。像咨询顾问，只给建议不干活。

「帮我写个排序算法」→ 它输出代码，你自己复制粘贴

🤖 AI Agent

你给个目标，它自己想办法完成。像实习生，你说需求它来执行。

「帮我做个登录页面」→ 它自己规划、写代码、测试、修复

Agent 的核心能力：

🎯 理解目标
→
📋 制定计划
→
🔧 调用工具
→
🔄 循环执行
→
✅ 完成任务

代表产品：Claude Code、Cursor、OpenAI Codex、Devin、Manus 等。

智能体 Tool Use / Function Calling（工具调用 / 函数调用）

一句话理解：让 AI 不只是说话，还能「动手干活」——调用外部函数和工具。

通俗解释：你问 AI「北京今天天气怎么样？」，AI 本身不知道实时天气。但如果有 get_weather(city) 这个工具，AI 就能自动调用它获取真实天气数据，然后告诉你。

Function Calling 是 OpenAI 最早提出的概念，Tool Use 是 Anthropic 的叫法，本质一样——让 AI 决定什么时候该调用什么工具，并传什么参数。

// AI 看到你的问题后，自动决定调用工具
{
  "tool": "get_weather",
  "arguments": { "city": "北京" }
}

// 拿到结果后，AI 再回答你
"北京今天 28°C，晴天，适合出门。"
智能体 RAG（检索增强生成）Retrieval-Augmented Generation

一句话理解：RAG 就是让 AI 「翻书找答案」再回答你，而不是凭记忆瞎编。

通俗解释：AI 的知识有截止日期（比如 Claude 的知识到 2025 年初），你问它 2026 年的新闻它不知道。RAG 的做法是：先从你的文档库里检索相关内容，然后把找到的内容给 AI 看，让 AI 基于这些真实内容来生成回答。

❓ 你的问题
→
🔍 搜索文档库
→
📄 找到相关内容
→
🤖 AI 基于内容回答
为什么重要：RAG 解决了 AI 的两大问题：①知识过时 ②不知道你的私有数据。现在几乎所有企业 AI 应用都用 RAG。
智能体 CoT（思维链）Chain of Thought

一句话理解：让 AI 「一步一步想」再回答，而不是直接蹦出答案。

通俗解释：你问一个复杂问题，如果直接要答案，AI 可能答错。但如果你让它「一步步想」，准确率会高很多。就像数学考试，写出解题步骤比直接写答案更靠谱。

推理模型（如 OpenAI o1/o3、Claude 的 extended thinking）就是把 CoT 内化了——模型自动在回答前进行深度思考。

🏋️模型训练层

了解这些概念，你就能看懂 AI 技术文章里那些「RLHF」「LoRA」到底在说什么。

训练 SFT（监督微调）Supervised Fine-Tuning

一句话理解：给 AI 上「专业课」，让它从通才变成专家。

通俗解释：基础模型什么都会一点，但不够专业。SFT 就是拿一批「问题-标准答案」的教材来教它，让它在某个领域更专业。比如拿大量医疗问答数据训练，它就变成医疗 AI。

🧠 基础模型（通才）
→
📚 喂专业教材
→
👨‍⚕️ 领域专家
训练 RLHF / DPO / GRPO（对齐训练）

一句话理解：教 AI 什么该说、什么不该说，让它的回答更符合人类偏好。

通俗解释：基础模型学会了语言，但不知道人类喜欢什么样的回答。对齐训练就是教它：

  • 要有礼貌，不要说脏话
  • 要诚实，不要编造事实
  • 要安全，不要教人做坏事
方法全称通俗理解
RLHFReinforcement Learning from Human Feedback人类给 AI 的回答打分，AI 根据分数自我改进
DPODirect Preference Optimization简化版 RLHF，直接比较「好回答」和「差回答」
GRPOGroup Relative Policy OptimizationDeepSeek 提出的新方法，更高效的对齐训练
训练 LoRA / QLoRA / 量化（Quantization）

一句话理解：用更少的资源（显卡、钱）来训练和运行 AI 模型。

通俗解释：

  • LoRA（Low-Rank Adaptation）：不全量训练模型，只训练一小部分参数。就像给一本书加批注，而不是重写整本书。成本低 90%+。
  • 量化（Quantization）：把模型从高精度压缩到低精度。就像把 4K 视频压缩成 1080P，画质略降但体积小了很多。
  • QLoRA = 量化 + LoRA，先压缩再微调，在消费级显卡上就能跑。
为什么重要：没有这些技术，你需要花几百万美元训练一个模型。有了它们，几千美元甚至免费就能在个人电脑上微调自己的 AI 模型。
训练 MoE（混合专家模型）Mixture of Experts

一句话理解：MoE 就像一个公司有很多部门，每次任务只激活相关部门，而不是全员出动。

通俗解释：传统模型处理每个问题时，所有参数都参与计算（全员出动）。MoE 模型把参数分成多个「专家组」，每次只调用最相关的几个专家。这样模型可以很大（能力强），但计算量不会成比例增长。

代表模型：GPT-4、DeepSeek-V3、Mixtral 都使用了 MoE 架构。

🚀应用与趋势层

这些是 2025-2026 年最热门的 AI 应用方向。

🔥 热门 Vibe Coding（氛围编程）

一句话理解：不用写代码，用自然语言描述你想要什么，AI 帮你写。编程变成了一种「感觉对了就行」的事。

通俗解释：以前写代码需要学编程语言。Vibe Coding 让你只需要用中文/英文描述你要什么，AI 来写代码。你不一定要理解每一行代码，只要最终效果「感觉对了」就行。

代表工具：Cursor、Claude Code、v0 by Vercel、Lovable、Bolt.new、Replit 等。

争议：专业开发者担心 Vibe Coding 产出的代码质量不可控。但随着 AI 能力提升和工具链（如 Superpowers）的完善，代码质量正在快速改善。
🔥 热门 Deep Research（深度研究）

一句话理解：让 AI 替你做深度调研——自动搜索、阅读、分析大量资料，然后给你一份完整的研究报告。

通俗解释：以前做调研，你要自己 Google、读论文、整理笔记。现在告诉 AI「帮我研究一下 XX」，它会自动搜索几十个网页、读论文、交叉验证，最后给你一份带引用的完整报告。

代表产品：ChatGPT Deep Research、Gemini Deep Research、Perplexity Pro、Grok 等。

趋势 Computer Use（计算机操控）

一句话理解：AI 直接看着你的屏幕，帮你操作电脑——点击、输入、打开应用。

通俗解释：AI 不再只是文字对话，它能「看到」你的电脑屏幕，像人一样操作鼠标和键盘。你可以说「帮我把这个 Excel 里的数据整理成图表」，它会自己打开 Excel、选中数据、创建图表。

代表产品：Claude Computer Use、OpenAI Operator、Google Project Mariner 等。

趋势 Reasoning Models（推理模型）

一句话理解：新一代 AI 模型会「深度思考」了——在回答前花时间推理，解决复杂数学和编程问题。

通俗解释：传统 AI 是「快问快答」。推理模型是「深思熟虑」——面对复杂问题，它会在内部进行大量思考和验证，然后再给出答案。

模型公司特点
o1 / o3 / o4-miniOpenAI推理能力强，擅长数学和编程
Claude with Extended ThinkingAnthropic可展示思考过程，长链推理
Gemini 2.5 ProGoogle内置推理能力，多模态
DeepSeek-R1DeepSeek开源推理模型，性价比高
🔥 热门 Agentic Workflow（智能体工作流）

一句话理解：让多个 AI Agent 按照工作流程自动协作，像一支训练有素的团队。

通俗解释：一个 Agent 不够用？Agentic Workflow 让多个 Agent 分工合作。比如：

📝 规划 Agent
拆解任务
→
💻 编码 Agent
写代码
→
🔍 审查 Agent
检查质量
→
🧪 测试 Agent
跑测试

这正是 Superpowers 项目在做的事情——通过 Skill 系统定义每个 Agent 的职责和工作流程。

🕸️概念关系图谱

所有关键词不是孤立存在的，它们之间有着紧密的联系：

🧠

模型基座

LLM 是一切的基础。通过 SFT 微调和 RLHF 对齐后变成有用的助手。MoE 让模型更大但计算更省。LoRA 让微调更便宜。

📡

连接协议

MCP 让 AI 连接工具，A2A 让 AI 之间协作。Skill 定义 AI 的行为规范。三者共同构成了 AI Agent 的「神经系统」。

🤖

智能体能力

Agent 通过 Tool Use 调用外部能力，通过 RAG 获取私有知识，通过 CoT 进行深度推理。这些能力让 AI 从「聊天机器人」变成「工作者」。

🚀

应用前沿

Agent 能力催生了 Vibe Coding、Deep Research、Computer Use 等新应用。多个 Agent 组成 Agentic Workflow 完成复杂任务。

一句话串起所有概念

基于 LLM 大语言模型（使用 MoE 架构降低成本），通过 SFT 微调和 RLHF 对齐训练变成有用的助手。用户输入的 Token 经过 Embedding 向量化存储在 向量数据库 中供 RAG 检索。AI 通过 MCP 协议连接外部工具，通过 A2A 协议与其他 AI 协作。 Skill 技能系统定义了 AI 的行为规范。 AI Agent 利用 Tool Use 调用工具，使用 CoT 思维链进行推理，通过 Agentic Workflow 组成团队完成复杂任务。这就是 Vibe Coding、Deep Research 和 Computer Use 等前沿应用的基础。
